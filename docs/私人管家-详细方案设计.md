## 1. 项目概述

### 1.1 系统简介

RightHand 是一个基于 Go + Vue 技术栈的个人与团队事务管理平台，采用前后端分离的单体架构设计。系统提供用户权限管理、备忘录管理、任务管理三大核心功能模块。

### 1.2 系统特点

- **高性能**：Go 语言的高并发特性保障系统性能
- **易维护**：清晰的三层架构和模块化设计
- **安全性**：JWT + Casbin 双重认证授权机制
- **灵活性**：支持周期性任务、多视图切换等高级功能

### 1.3 技术架构

- **前端**：Vue 3 + Element Plus + Pinia + Vue Router
- **后端**：Go 1.24.8 + Gin + GORM + Casbin
- **数据库**：MySQL 8.0+
- **部署**：支持直接部署和 Docker 容器化部署

### 3.2 分层架构

系统采用经典的三层架构：

**Handler 层（表现层）**
- 接收 HTTP 请求
- 参数解析和验证
- 调用 Service 层
- 返回 HTTP 响应

**Service 层（业务逻辑层）**
- 实现核心业务逻辑
- 事务管理
- 调用 Repository 层
- 数据转换和处理

**Repository 层（数据访问层）**
- 数据库 CRUD 操作
- SQL 查询封装
- 数据映射

### 3.3 Casbin 权限控制

#### 3.3.1 Casbin 模型配置

**model.conf：**
```ini
[request_definition]
r = sub, obj, act

[policy_definition]
p = sub, obj, act

[role_definition]
g = _, _

[policy_effect]
e = some(where (p.eft == allow))

[matchers]
m = g(r.sub, p.sub) && r.obj == p.obj && r.act == p.act
```

#### 3.3.2 Casbin 初始化

```go
// internal/middleware/casbin.go
func InitCasbin(db *gorm.DB) error {
    adapter, err := gormadapter.NewAdapterByDB(db)
    if err != nil {
        return err
    }
    
    Enforcer, err = casbin.NewEnforcer("configs/model.conf", adapter)
    if err != nil {
        return err
    }
    
    return Enforcer.LoadPolicy()
}
```

### 3.4 JWT 认证

```go
// internal/utils/jwt.go
type Claims struct {
    UserId   int64    `json:"userId"`
    Username string   `json:"username"`
    Roles    []string `json:"roles"`
    jwt.RegisteredClaims
}

func GenerateToken(userId int64, username string, roles []string) (string, error) {
    claims := Claims{
        UserId:   userId,
        Username: username,
        Roles:    roles,
        RegisteredClaims: jwt.RegisteredClaims{
            ExpiresAt: jwt.NewNumericDate(time.Now().Add(2 * time.Hour)),
            Issuer:    "righthand",
        },
    }
    
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    return token.SignedString(jwtSecret)
}
```

### 4.2 Axios 封装

```javascript
// src/utils/request.js
const service = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || 'http://localhost:9080',
  timeout: 30000
})

// 请求拦截器 - 自动添加 Token
service.interceptors.request.use(config => {
  const token = localStorage.getItem('righthand_token')
  if (token) {
    config.headers['Authorization'] = `Bearer ${token}`
  }
  return config
})

// 响应拦截器 - 统一错误处理
service.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.message || '请求失败')
      if (res.code === 401) {
        localStorage.removeItem('righthand_token')
        router.push('/login')
      }
      return Promise.reject(new Error(res.message))
    }
    return res
  },
  error => {
    ElMessage.error(error.message || '网络错误')
    return Promise.reject(error)
  }
)
```

## 7. 安全方案详细设计

### 7.1 JWT 认证流程

1. 用户登录，验证用户名密码
2. 生成 JWT Token（包含用户 ID、用户名、角色）
3. 前端存储 Token（localStorage）
4. 后续请求在 Header 中携带 Token
5. 后端中间件验证 Token 有效性
6. Token 过期后重新登录

### 7.2 Casbin 权限校验流程

1. 用户登录后，加载用户角色和权限到 Casbin Enforcer
2. 前端通过权限指令控制 UI 元素显示
3. 后端请求经过 Casbin 中间件验证权限
4. 无权限请求返回 403 Forbidden

### 7.3 密码安全

- 使用 BCrypt 算法加密存储密码
- 密码强度要求：至少 8 位，包含大小写字母、数字
- 禁止明文传输密码（使用 HTTPS）

### 7.4 数据安全

- **SQL 注入防护**：使用 GORM 参数化查询
- **XSS 防护**：前端输入转义
- **CORS 配置**：限制跨域访问
- **HTTPS**：生产环境强制使用 HTTPS

### 8.2 Docker 部署

**重要说明**：Docker 部署时不包含 MySQL 服务，直接使用本机已部署的 MySQL 数据库。

```yaml
version: '3.8'

services:
  backend:
    build: ./righthand-go
    ports:
      - "9080:9080"
    environment:
      - DB_HOST=host.docker.internal
      - DB_PORT=3306
      - DB_USER=root
      - DB_PASSWORD=your_password
      - DB_NAME=righthand
    extra_hosts:
      - "host.docker.internal:host-gateway"
  
  frontend:
    build: ./righthand-frontend
    ports:
      - "80:80"
    depends_on:
      - backend
```

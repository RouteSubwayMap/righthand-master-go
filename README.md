# 私人管家系统使用说明

## 系统概述

私人管家系统是一款基于 Web 的个人事务管理平台，帮助用户高效管理日常任务、需求和联系人信息。系统采用现代化的前后端分离架构，提供直观易用的用户界面。

## 功能模块

### 1. 仪表盘

仪表盘是系统的首页，提供数据概览和快速操作入口。

**主要功能：**
- 任务状态统计（待办、进行中、已完成、已取消）
- 快速创建任务入口
- 近期任务列表展示

**操作说明：**
- 点击任务卡片可快速查看任务详情
- 通过操作按钮直接更改任务状态

### 2. 事项管理

事项管理模块用于管理个人任务和备忘录。

**功能特性：**
- 任务列表展示（支持分页）
- 任务状态流转：待办 → 进行中 → 已完成/已取消
- 任务创建、编辑、删除
- 周期性任务支持

**状态流转规则：**

| 当前状态 | 可执行操作 |
|---------|-----------|
| 待办 (TODO) | 开始处理 → 进行中 |
| 待办 (TODO) | 取消 → 已取消 |
| 进行中 (DOING) | 完成 → 已完成 |
| 进行中 (DOING) | 取消 → 已取消 |
| 已完成 (DONE) | 删除 |
| 已取消 (CANCELLED) | 删除 |

**创建任务说明：**
1. 点击「新建任务」按钮
2. 填写任务标题和描述
3. 设置优先级（高/中/低）
4. 选择截止时间（可选）
5. 如需周期性任务，设置重复规则
6. 点击「保存」完成创建

### 3. 需求管理

需求管理模块用于跟踪项目需求和功能开发进度。

**功能特性：**
- 需求列表展示（支持分页）
- 需求状态管理
- 需求导入导出
- 优先级排序

**需求状态：**
- PENDING_CLARIFY - 待澄清
- PENDING_SCHEDULING - 待排期
- DEVELOPING - 开发中
- TESTING - 测试中
- PENDING_RELEASE - 待发布
- COMPLETED - 已完成

### 4. 联系人管理

联系人管理模块用于管理个人和工作联系人信息。

**功能特性：**
- 看板模式展示（按分组显示）
- 列表模式展示
- 联系人创建、编辑、删除
- 分组管理

**看板模式说明：**
- 联系人按预设分组展示
- 仅显示包含数据的分组
- 支持拖拽操作调整联系人位置

## 系统操作指南

### 登录系统

1. 打开浏览器访问系统地址：`http://localhost` 或局域网地址 `http://10.252.20.59`
2. 输入用户名和密码
3. 点击「登录」按钮进入系统

### 退出系统

点击页面右上角的用户头像，选择「退出登录」。

### 数据权限

- **普通用户**：只能查看和管理自己创建的数据
- **超级管理员**：可以查看所有用户的数据

## 技术支持

### 系统配置

**后端服务：**
- 服务地址：`http://localhost:8090/api/`
- 数据库：MySQL 8.0+

**前端服务：**
- 服务地址：`http://localhost`
- 端口：80

### 常见问题

**Q1：页面显示空白或无法加载？**

A：请检查后端服务是否正常运行，确保 Docker 容器已启动。

**Q2：任务截止时间显示不正确？**

A：系统使用本地时区显示时间，请确保您的设备时区设置正确。

**Q3：如何让局域网其他电脑访问系统？**

A：需要配置 Windows 防火墙允许端口 80 和 8090 的入站连接。

**Q4：忘记密码怎么办？**

A：请联系系统管理员重置密码。
